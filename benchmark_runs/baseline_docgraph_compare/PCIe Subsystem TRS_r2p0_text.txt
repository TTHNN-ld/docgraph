REQ_PCIE_TRS_021: Chip 内部 Master 访问内部资源需通过 Local 地址段
◼ Chip 内的 Master （ GPU, CPU, SoC DMA, ，访问 Chip 内的资源（包括同一个 Chip 中的不同 Die ），需要通过 Local Memory + IO 地址段进行 （最低 512Gbyte ）

◼ 需要进行'跨卡访问'的 Master （如 GPU ），需要通过 MMU ，将内部的 Local 空间映射到统一的 C2C 96T 地址空间上

5.2.1 BAR Space assignment
REQ_PCIE_TRS_043: PCIE 支持 1 个 64bit MEM BAR 和 1 个 32bit REG BAR ，以及 1 个 32bit BAR 用于 PCIe Controlller 内部寄存器访问
◼ 64bit MEM BAR 用于访问 seDRAM 空间
◼ 32bit REG BAR 用于访问低 4G 的 Configuration Register 空间，包括 CPU 子系统中的 Cluster Memory
◼ 两种 BAR 均为 MEM 类型，其中
◆ MEM BAR 为 Prefetchable
◆ REG BAR 为 non-prefetchable
REQ_PCIE_TRS_044: Inbound Access 可以访问到 CHIP 中两个 DIE 的所有地址空间
包括 Die0/Die1 的配置寄存器空间， SeDRAM 的不同 Interleave 映射空间
REQ_PCIE_TRS_045: Inbound Access 无法访问 PCIE Outbound 地址空间
避免出现 Deadlock
REQ_PCIE_TRS_046: Remote 可以通过 REG BAR 访问 PCIe Controller 的配置寄存器
◼ 同样也可以通过 Configuration 访问
◼ 当通过 BAR 访问时，需避免 NoC Deadlock
REQ_PCIE_TRS_047: Host 可以通过 REG BAR 访问 MSI-X Table SRAM

REQ_PCIE_TRS_103: 该功能不实现的！
REQ_PCIE_TRS_100: 需要实现 eATU ，实现 AXI 域的 SoC PA 到 IOVA 的映射
◼ 由于 IP ATC 实现接口在 ATC 外部，所以需要在 Master 到 ATC 之间实现类似 iATU 的功能 --eATU(external ATU) ，以实现 SoC PA 到 IOVA 的映射
◼ Outbound 地址空间 128T 相对足够，因此这里的 eATU window 数量不需要很多
REQ_PCIE_TRS_101: 支持 ATS 功能， ATC 负责将 IOVA 映射为 PA
当使能 ATS 功能， dataflow 大致流程如下：
GPU/CPU 通过 MMU 发送 SoC PA 到 PCIe AXI Slave 上（ 512G ~ 128T ）
经过自研的 oATU 模块，将 47bit 的 SoC PA 映射为 64bit 的 IOVA
AXI Request 传递到自研的 ATC 模块
3.1 ATC 中 TLB Miss ， 发送 ATS Request 给 Host 的 IOMMU 。此时 AXIS Slave 侧接收 AR/AW Request 后应 stall 住，等待 translate 完成
3.2 IOMMU 返回 Translation Complete TLP
3.3 ATC 进行 IOVA->PA 翻译，发送给 PCIe Controller
PCIe Controller 此时应将 TLP 发送出去，并 AT=0b10
REQ_PCIE_TRS_102: 如果 ATS Request fail ， ATC Terminate AXI Transaction ，并上报中断
◼ 当出现 Page Fault 。此时 LD/ST 任务应 terminate ，并上报中断给 MCPU
◼ 无需上报中断给 HOST （ HOST 的 IOMMU 自己会有中断）
◼ 通过 PRS 接口，完成后再次发起 LD/ST 访问请求。

6.4 Performance
REQ_PCIE_TRS_250: 支持的最大 AXI Master/Slave Burst Length 为 256Byte
避免过大 Burst 影响 NoC 的 Congestion
REQ_PCIE_TRS_251: AXI Master 上的 ID 应是 Unique 的
◼ 需要 AXI Master 提供 Unique ID 以实现更高的性能。
◼ 对应就需要足够的 Reorder Buffer
◼ ROB 的位置可以在 NoC 上或 PCIe Controller 中。
REQ_PCIE_TRS_252: GPU 通过 AXI Slave 进行 outbound 访问速率要求达到单向 54GB/s （ x16 Mode ）
REQ_PCIE_TRS_253: DMA 在 Max Payload Size 情况下的速率要求达到单向 54GB/s （ x16 Mode ）
◼ 考虑到 TLP Overhead ， Link Protocol Overhead ， Flow Control Protocol Overhead ，利用率 ~85%
◼ 需要在 Inbound/Outbound 同时工作的情况下达到这一要求（单向 54/27GB/s ，双向 54/108GB/s ）
◼ 需要考虑不同的 round-trip Latency 情况是否都可满足该要求
◼ 相关因素包括但不限于：
◆ NoC 的设置，比如 outstanding ， ROB 等
◆ PCIe Controller 中相关参数， Max Outbound NP Request ， Tag 宽度等

REQ_PCIE_TRS_284: 支持 Link list mode ，粒度支持 1Byte~4GByte
REQ_PCIE_TRS_286: PCIe 内的 DMA 不支持 2D/3D Copy
