# DocGraph RFCs

重大变更（破坏性 API / schema / 跨模块设计）走 RFC 流程。

## 流程

1. 复制 [0000-template.md](./0000-template.md) → `XXXX-your-proposal.md`（X 用下一个空闲编号）
2. 提 PR 标题：`RFC: <标题>`
3. 至少 2 位 maintainer review
4. accepted / rejected / postponed
